# دليل إطلاق سوق الشطرة 2

اتبع الخطوات بالترتيب. الخطوات ١–٤ ضرورية قبل فتح الموقع للزبائن.

## ١. خذ نسخة احتياطية من قاعدة البيانات

من Supabase: Database ← Backups. أو بالأمر:

```sh
supabase db dump --project-ref nbktyynshqldyerqtjrd -f backup-before-v2.sql
supabase db dump --project-ref nbktyynshqldyerqtjrd --schema-only -f schema.sql
```

احفظ `schema.sql` في المستودع: الجداول الأساسية (`products`, `orders`, `stores`, `profiles`…) أُنشئت من لوحة Supabase وليست موجودة كملفات، وهذا أهم نقص في المشروع.

## ٢. شغّل ترحيل الإيرادات

افتح Supabase ← SQL Editor، والصق محتوى:

```
supabase/migrations/20261014090000_marketplace_revenue.sql
```

ثم اضغط Run. الترحيل إضافي فقط: لا يحذف ولا يعدّل أي طلب أو سعر أو مخزون. اختُبر على نسخة محلية تحاكي قاعدتك (`npm run test:db`). مع ذلك، جرّبه أولًا على مشروع Supabase تجريبي إن أمكن.

> بدون هذه الخطوة يعمل الموقع كاملًا بالدفع عند الاستلام، وتظهر صفحات المالية والباقات والإعلانات برسالة «قيد التفعيل».

## ٣. انشر الموقع

ادمج الفرع في `main`. يعرض GitHub Pages الموقع الجديد مباشرة. الإصدار القديم يبقى متاحًا على `/legacy/` للرجوع إليه.

بعد النشر يستبدل عامل الخدمة الجديد (`sw.js`) القديم تلقائيًا ويمسح ذاكرته، فتظهر الواجهة الجديدة للمستخدمين الذين ثبّتوا التطبيق.

## ٤. اضبط الأسعار

ادخل `admin.html` بحساب المدير ← «الإعدادات والأسعار»:

1. **عمولة المتاجر الافتراضية.** اقتراح للبداية: ٣–٥٪. أبلغ التجار قبل التفعيل.
2. **حصة التوصيل.** اقتراح: ١٠٪ أو اتركها صفرًا في البداية لجذب السائقين.
3. **الباقات:** حدّد أسعار الفضية والذهبية (مثلًا ١٥٬٠٠٠ و٣٥٬٠٠٠ د.ع شهريًا) وحد المنتجات للباقة المجانية.
4. **أسعار الإعلانات اليومية.**
5. **حسابات استلام التحويلات:** رقم زين كاش ورقم كي كارد اللذان يحوّل إليهما التجار والسائقون.

الأسعار تُطبَّق على الطلبات التي تُسلَّم بعد الحفظ فقط.

## ٥. فعّل زين كاش (اختياري)

1. افتح حساب تاجر لدى زين كاش واحصل على: `msisdn`، و`merchantId`، و`secret`.
2. Supabase ← Edge Functions ← Secrets، وأضف:
   - `ZAINCASH_MSISDN`
   - `ZAINCASH_MERCHANT_ID`
   - `ZAINCASH_SECRET`
   - `ZAINCASH_BASE`: `https://test.zaincash.iq` للتجربة، ثم `https://api.zaincash.iq` للإنتاج
   - `ALLOWED_ORIGINS`: رابط موقعك، مثل `https://halguorabi76-netizen.github.io` (ورابط النطاق الخاص إن وُجد)
3. انشر الدالة: `supabase functions deploy payments --no-verify-jwt`
4. اختبر دفعة صغيرة في وضع الاختبار، ثم فعّل «زين كاش» من الإعدادات.

> تحقّق من وثائق زين كاش الحالية: إذا كان حسابك على واجهتهم الأحدث فقد تختلف عناوين `init` و`pay` عن المكتوبة في `supabase/functions/payments/index.ts`.

## ٦. البطاقات (كي كارد / ماستر)

تحتاج عقدًا مع بوابة دفع (Qi Card أو FIB أو غيرها) ووثائق الـ API الخاصة بها. أضف المحوّل في `supabase/functions/payments/index.ts` مكان `card_gateway_not_configured`، بنفس نمط زين كاش: المبلغ من `payment_create_intent` والتأكيد عبر `payment_complete_intent`.

## ٧. قائمة فحص قبل الإطلاق

- [ ] كل متجر معتمد حدّد **موقع الاستلام على الخريطة** (مركز البائع ← إعدادات المتجر). بدونه لا تُحسب أجرة التوصيل للطلبات من متجره.
- [ ] اطلب طلبًا حقيقيًا صغيرًا من حساب زبون، واقبله كبائع، وسلّمه كسائق، وتأكد من ظهوره في المالية.
- [ ] راجع نصوص «الشروط» و«الخصوصية» و«الإرجاع» (`app/shop/pages.js`) مع محامٍ.
- [ ] فعّل الدخول بـ Google من Supabase ← Authentication ← Providers (اختياري).
- [ ] في Supabase ← Authentication ← URL Configuration أضف رابط موقعك إلى Redirect URLs.
